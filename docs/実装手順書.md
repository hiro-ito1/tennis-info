## ⚙️ **ステップ5: GitHub Pages 設定変更**

### **5-1. 現在の設定を確認**

現在の設定:
```
Source: main ブランチの /.github から公開
```

これを変更します。

---

### **5-2. 設定変更手順**

#### **手順:**

1. GitHub のリポジトリページを開く
   ```
   https://github.com/hiro-ito1/tennis-info
   ```

2. 上部メニューの「Settings」をクリック

3. 左サイドバーの「Pages」をクリック

4. **Build and deployment** セクション

5. **Source** のドロップダウンをクリック

6. **「Deploy from a branch」を選択**（既に選択済みの場合もあり）

7. **Branch** セクション
   - 1つ目のドロップダウン: `main` を選択
   - 2つ目のドロップダウン: `/ (root)` を選択
   
   ⚠️ 重要: `/.github` ではなく `/ (root)` を選択

8. 「Save」ボタンをクリック

---

### **5-3. デプロイ完了を待つ**

#### **確認手順:**

1. リポジトリのトップページに戻る

2. 上部に黄色い丸（🟡）が表示される
   ```
   🟡 Deploying...
   ```

3. 数分後、緑のチェックマーク（✅）に変わる
   ```
   ✅ Deployed

3. **真っ白なページが表示される場合:**
   - `public/index.html` が正しく生成されているか確認
   - ローカルで `python admin.py` → 「HTMLを再生成」

#### **Q1: 管理画面が起動しない**
```
A: 以下を確認してください
- Python がインストールされているか
- Flask がインストールされているか
  → コマンド: pip install flask
- カレントディレクトリが正しいか
  → コマンド: cd C:\Users\tenni\tennis-info

#### **Q2: 公開ページに「404 Not Found」が出る**
```
A: GitHub Pages の設定を確認
- Settings → Pages
- Source が「/ (root)」になっているか
- デプロイが完了しているか（✅マーク）
```

#### **Q3: 設定タブが表示されない**
```
A: admin.py が正しく上書きされているか確認
- ファイルサイズを確認（約25KB）
- 最終更新日時を確認
```

#### **Q4: config.json のエラーが出る**
```
A: 構造を確認
- "sources" キーが存在するか
- JSON 形式が正しいか（カンマ、括弧）
```
